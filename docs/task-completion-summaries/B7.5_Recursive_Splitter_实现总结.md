**作用：** Recursive Splitter provider 实现，支持递归文本切分策略

**关键内容解读：**
- **RecursiveSplitter 类**：继承 BaseSplitter，实现递归文本切分
  - 默认分隔符层级：`["\n\n", "\n", " ", ""]` (从大到小)
  - `split_text(text)` 方法：主入口，处理输入验证
  - `_split_recursive(text, separator_index)` 方法：递归切分核心逻辑
  - `_split_by_size(text)` 方法：字符级切分（兜底方案）
  - `_apply_overlap(chunks)` 方法：在相邻 chunk 之间添加重叠
  - `_should_split_further(text, separator_index)` 方法：判断是否需要继续切分
- **递归策略**：
  1. 优先尝试大分隔符（如段落分隔 `\n\n`）
  2. 如果 chunk 仍然过大，递归尝试小分隔符（如 `\n`、` `）
  3. 最后兜底方案：按字符大小强制切分
- **文档结构保留**：
  - 优先按段落切分，避免打断段落
  - 优先按行切分，避免打断代码块
  - 通过 overlap 保证上下文连续性
- **错误处理增强**：
  - 空文本输入验证
  - 类型检查（必须是字符串）
  - 空分隔符特殊处理（直接跳到字符级切分）

## 🔑 关键设计解读

### Q1: 为什么要使用递归策略而不是固定分隔符？
**解释：** 固定分隔符（如只按段落切分）在处理复杂文档时会失效——有些段落可能非常大，导致单个 chunk 超出限制。递归策略提供了智能降级机制：优先保留大结构（段落），必要时才破坏小结构（行、单词）。

**类比：** 就像拆包裹一样，先尝试按大盒子拆，如果还是太大，再拆里面的中盒子，最后才拆小物品。

**好处：**
- 最大程度保留文档结构
- 避免 chunk 超出大小限制
- 自适应不同类型的文档

### Q2: 为什么需要 overlap（重叠）？
**解释：** 在文档检索中，如果句子正好在 chunk 边界被切断，检索时可能丢失上下文。通过在相邻 chunk 之间添加重叠，确保每个切分点都有足够的上下文信息。

**示例：**
```
Chunk 1: "... machine learning is a subset of artificial intelligence that \
 Chunk 2: intelligence that focuses on algorithms and statistical models"
```
（overlap 部分：`intelligence that`）

**好处：**
- 提高检索质量
- 避免关键信息在边界丢失
- 保持语义连贯性

### Q3: 空分隔符 `""` 有什么特殊含义？
**解释：** 在分隔符列表中，空字符串 `""` 是一个特殊标记，表示"按字符大小强制切分"。当所有其他分隔符都无法将文本切分成足够小的 chunk 时，使用这个兜底方案。

**处理逻辑：**
```python
if separator == "":
    return self._split_by_size(text)  # 直接按字符大小切分
```

**好处：**
- 提供保证有效的切分方案
- 处理极端情况（如无分隔符的连续文本）
- 确保 chunk_size 限制始终得到满足

## 🔧 使用示例

### 基本使用
```python
from src.libs.splitter.recursive_splitter import RecursiveSplitter

# 创建 Recursive Splitter
splitter = RecursiveSplitter(
    chunk_size=1000,
    chunk_overlap=200
)

# 切分文本
text = """# Introduction

Machine learning is a subset of AI.

## Key Concepts

- Supervised learning
- Unsupervised learning
- Reinforcement learning
"""

chunks = splitter.split_text(text)

# 访问结果
print(f"Generated {len(chunks)} chunks")
for i, chunk in enumerate(chunks):
    print(f"Chunk {i}: {len(chunk)} chars")
```

### 自定义分隔符
```python
# 自定义分隔符顺序
splitter = RecursiveSplitter(
    chunk_size=500,
    chunk_overlap=100,
    separators=["|||", "\n\n", "\n", " ", ""]
)

chunks = splitter.split_text("Part|||Part|||Part")
```
