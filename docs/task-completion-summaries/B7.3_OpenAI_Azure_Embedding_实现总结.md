- **批量处理**：
  - 自动将输入文本列表分成批次（每批最多 batch_size 个）
  - 每批次调用一次 API，提高效率
  - 合并所有批次的结果
- **输入校验**：
  - 空列表检查：抛出 ValueError
  - 类型检查：确保所有元素都是字符串

  - HTTP 错误：包含 provider 名称、模型名、错误详情
  - 网络错误：清晰的错误信息
  - 所有错误都包含 `[openai]` 标识

**Python 概念解释：**
- **继承 (Inheritance)**：AzureEmbedding 继承 OpenAIEmbedding，复用代码
- **批量处理**：将大列表分成小块处理，避免超过 API 限制

## 🔑 关键设计解读

### Q1: 为什么 Azure Embedding 继承 OpenAI Embedding？

**解释：**
Azure OpenAI 和 OpenAI 使用完全相同的 API 格式和响应结构，只是 endpoint 不同。通过继承，Azure Embedding 可以复用 OpenAI Embedding 的所有核心逻辑（批量处理、输入校验、结果合并等），只需重写 `_embed_batch` 方法来适配 Azure 的 URL。

**实现方式：**
```python
class AzureEmbedding(OpenAIEmbedding):
    def __init__(self, ..., azure_endpoint, api_version, ...):
        # Azure 特有的初始化
        self.embedding_url = f"{azure_endpoint}/openai/deployments/{model}/embeddings?api-version={api_version}"

    def _embed_batch(self, texts, **kwargs):
        # 重写此方法，使用 Azure 的 URL
        response = self._client.post(self.embedding_url, ...)
        # 其余逻辑完全相同
```

**好处：**
- ✅ 代码复用率高达 90%
- ✅ 行为一致性得到保证
- ✅ 维护成本降低（修改一次，两处生效）

---

### Q2: 为什么要实现批量处理（batch processing）？

**解释：**
Embedding API 通常支持一次请求处理多个文本，这样可以：
1. 减少网络往返次数（提高性能）
2. 降低 API 调用成本（大多数提供商按请求计费）
3. 提高吞吐量

**实现逻辑：**
```python
def embed(self, texts: List[str]) -> EmbeddingResult:
    all_embeddings = []

    # 分批处理
    for i in range(0, len(texts), self.batch_size):
        batch = texts[i:i + self.batch_size]
        batch_embeddings = self._embed_batch(batch)  # 单批次 API 调用
        all_embeddings.extend(batch_embeddings)

    return EmbeddingResult(embeddings=all_embeddings, ...)
```

**类比：**
就像坐电梯，一次能装多个人，比每个人单独坐电梯效率高得多。

**好处：**
- ✅ 性能提升：减少网络延迟
- ✅ 成本降低：更少的 API 调用次数
- ✅ 可扩展性：支持任意数量的文本

### Q3: 空输入和超长输入如何处理？

**解释：**
- **空输入（空列表）**：抛出 ValueError，提示用户至少提供一个文本
- **空字符串（"" 或 "  "）**：记录警告但继续处理（API 仍会返回向量，但质量可能较低）
- **超长输入**：由 API 端处理，会返回错误或截断（取决于模型）

**实现代码：**
```python
# 空列表检查
if not texts:
    raise ValueError("Texts list cannot be empty.")

# 空字符串警告
if any(text.strip() == "" for text in texts):
    logger.warning("Some texts are empty or contain only whitespace.")
```

**好处：**
- ✅ 快速失败（Fail fast）：空列表立即返回错误
- ✅ 柔性处理：空字符串记录警告但不阻塞
- ✅ 清晰的错误信息：帮助用户理解问题
