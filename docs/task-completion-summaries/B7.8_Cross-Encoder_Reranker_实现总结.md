## 📁 创建的文件

### 1. `src/libs/reranker/cross_encoder_reranker.py`
**作用：** Cross-Encoder 模型驱动的精排重排序实现

**关键内容解读：**
- **CrossEncoderReranker 类**：继承 BaseReranker，实现 cross-encoder 精排
  - `scorer`: 可插拔 scorer 函数，签名 `(query: str, content: str) -> float`
  - `timeout`: 超时保护（默认 30 秒）
  - `_default_scorer`: 内置占位符 scorer（关键词匹配）

- **核心方法：**
  - `_score_with_timeout(query, candidate)`: 为单个候选人打分，带超时保护
    - 调用 scorer 函数计算相关性分数
    - 检查是否超时，超时则抛出 TimeoutError
    - 捕获 scorer 异常并记录日志
  - `rerank(query, candidates, **kwargs)`: 主逻辑
    1. 验证输入（非空 candidates）
    2. 遍历所有候选人并打分
    3. 捕获超时和错误，使用原始分数
    4. 按分数降序排序
    5. 截断到 top_k
    6. 返回 RerankResult
  - `get_statistics()`: 获取统计信息
    - `total_rerank_calls`: 总调用次数
    - `total_candidates_scored`: 总成功打分人数
    - `total_fallback_count`: 总降级次数
  - `reset_statistics()`: 重置统计信息

- **降级机制：**
  - 单个候选人超时：使用原始分数，继续处理其他候选人
  - 单个候选人错误：使用原始分数，继续处理其他候选人
  - 全局异常：返回原始顺序，设置 `fallback_triggered=True`

- **默认 scorer 策略：**
  - 简单关键词匹配：`score = matches / max(words, 1)`
  - 用于测试和占位，生产环境应使用真实模型

## 🔑 关键设计解读

### Q1: 什么是 Cross-Encoder 模型？
**解释：** Cross-Encoder 是一种深度学习模型，它将 query 和 document 一起输入到模型中，得到一个相关性分数。与 Bi-Encoder（分别编码 query 和 document）不同，Cross-Encoder 在计算时同时看到 query 和 document，因此精度更高但速度更慢。

**对比：**
- **Bi-Encoder**: 独立编码 → 向量相似度 → 快速但精度较低
- **Cross-Encoder**: 联合编码 → 直接打分 → 精度高但较慢

**适用场景：**
- 精排（Reranking）：对 Bi-Encoder 检索的 Top-M 结果进行精排
- 小规模数据：通常只对 Top-50~Top-100 结果进行精排
- 高精度要求：搜索、推荐系统

### Q2: 为什么要设计可插拔 scorer 函数？
**解释：** 不同场景可能使用不同的 cross-encoder 模型，设计为可插拔函数可以：
- 支持多种模型（sentence-transformers、HuggingFace、自定义）
- 方便测试（mock scorer 返回固定分数）
- 避免硬编码模型依赖

### Q3: 为什么要实现超时保护？
**解释：** Cross-Encoder 模型推理可能较慢（特别是大型模型），如果没有超时保护，可能导致：
- 请求长时间阻塞
- 系统资源耗尽
- 用户体验差

**超时保护机制：**
```python
start_time = time.time()
score = scorer_func(query, candidate.content)
elapsed = time.time() - start_time

if elapsed > self.timeout:
    raise TimeoutError(f"Scoring exceeded timeout of {self.timeout}s")
```

**超时处理策略：**
- 单个候选人超时：使用原始分数，继续处理其他人
- 不影响整个 rerank 流程
- 记录警告日志便于监控

### Q4: 降级机制与 LLM Reranker 有何不同？
**解释：** 两种 Reranker 的降级策略不同：

**LLM Reranker:**
- 全局失败：LLM 调用失败 → 返回原始顺序
- 解析失败：JSON 解析失败 → 返回原始顺序
- 粒度：整个 rerank 操作

**Cross-Encoder Reranker:**
- 单个失败：某个候选人打分失败 → 使用原始分数
- 全局失败：所有候选人都失败 → 返回原始顺序
- 粒度：每个候选人独立

**优势：**
- 更细粒度的降级
- 部分成功时仍能获得改进的结果
- 更好的容错性

### Q5: 为什么要追踪统计信息？
**解释：** 统计信息用于监控和调试：
- `total_rerank_calls`: 调用次数，用于计算平均延迟
- `total_candidates_scored`: 成功打分数，用于计算成功率
- `total_fallback_count`: 降级次数，用于监控模型健康度

**监控指标示例：**
```python
stats = reranker.get_statistics()
avg_latency = total_time / stats["total_rerank_calls"]
success_rate = stats["total_candidates_scored"] / total_candidates
fallback_rate = stats["total_fallback_count"] / stats["total_rerank_calls"]
```

def create_mock_scorer(scores: dict) -> callable:

    return random.random()

    global counter
    counter += 1
    return counter * 0.1

## 🔧 使用示例

### 基本使用（默认 scorer）
```python
from src.libs.reranker.cross_encoder_reranker import CrossEncoderReranker
from src.libs.reranker.base_reranker import RerankCandidate

# 创建 CrossEncoderReranker（使用默认 scorer）
reranker = CrossEncoderReranker(
    top_k=5,
    model="ms-marco-MiniLM-L-6",
    timeout=30.0
)

# 准备候选人
candidates = [
    RerankCandidate(
        id="chunk1",
        content="Machine learning is a subset of artificial intelligence...",
        score=0.85,  # 原始向量相似度分数
        metadata={"source": "textbook.pdf", "page": 42}
    ),
    RerankCandidate(
        id="chunk2",
        content="Deep learning uses neural networks with multiple layers...",
        score=0.78,
        metadata={"source": "paper.pdf", "page": 3}
    ),
]

# 重排序
result = reranker.rerank(
    query="What is machine learning?",
    candidates=candidates
)

# 检查结果
print(f"Method: {result.method}")  # "cross_encoder"
print(f"Top candidate: {result.candidates[0].id}")  # "chunk1" (最相关)
print(f"New score: {result.candidates[0].score}")  # 0.95 (来自 scorer)
```
