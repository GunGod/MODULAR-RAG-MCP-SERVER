## 🔑 关键设计解读

### Q1: 为什么选择 ChromaDB？
**解释：** ChromaDB 是一个嵌入式向量数据库，`pip install chromadb` 即可使用，无需 Docker 容器或外部服务。非常适合本地开发、快速原型验证和小规模部署。

**优点：**
- 零配置开箱即用
- 本地持久化（SQLite + hnswlib）
- 支持元数据过滤
- 兼容 OpenAI API 格式
- 轻量级（相比 Qdrant、Milvus）

**缺点：**
- 不支持大规模分布式部署
- 性能不如专业向量数据库

### Q2: 为什么要转换距离为分数？
**解释：** ChromaDB 返回的是"距离"（distance），值越小表示越相似。但 BaseVectorStore 接口定义的 QueryResult.score 应该是"相似度分数"，值越大表示越相似。为了一致性，需要转换。

**转换公式：**
- Cosine 距离：`score = 1.0 - distance`
- 距离范围：[0, 2] → 分数范围：[1, -1]
- 分数为 1 表示完全相同，0 表示正交，-1 表示完全相反

### Q3: ChromaDB metadata 限制如何处理？
**解释：** ChromaDB 对 metadata 有严格要求：
- 不能是 None
- 不能是空字典 `{}`（会报错）
- 每个键值对必须有实际意义

**解决方案：**
- 如果 record.metadata 是 None 或空，添加 dummy metadata
- 使用 `{"_dummy": "true"` 作为占位符
- 不影响查询功能（用户一般不会过滤这个字段）

### Q4: Windows 文件锁定问题如何解决？
**解释：** ChromaDB 使用 SQLite，在 Windows 上容易出现文件句柄未释放的问题，导致测试 cleanup 时删除临时目录失败。

**解决方案：**
1. 实现 `close()` 方法释放客户端引用
2. 在 cleanup 前调用 `gc.collect()` 强制垃圾回收
3. 添加短暂延迟（0.2秒）等待 Windows 释放文件句柄
4. 使用 try-except 捕获 PermissionError，忽略清理失败
5. 使用 `shutil.rmtree(..., onerror=...)` 处理只读文件

## 🔧 使用示例

### 基本使用
```python
from src.libs.vector_store.chroma_store import ChromaStore

# 创建 ChromaStore
store = ChromaStore(
    collection_name="documents",
    persist_path="./data/chroma"
)

# Upsert 向量记录
records = [
    VectorRecord(
        id="doc1",
        vector=[0.1, 0.2, 0.3, ...],
        metadata={"source": "report.pdf", "page": 1},
        payload="This is the document content."
    ),
    VectorRecord(
        id="doc2",
        vector=[0.4, 0.5, 0.6, ...],
        metadata={"source": "email.txt"},
        payload="Email content goes here."
    ),
]
result = store.upsert(records)
print(f"Upserted {result.upserted_count} records")

# 查询相似向量
query_vector = [0.15, 0.25, 0.35, ...]
results = store.query(vector=query_vector, top_k=5)

for result in results:
    print(f"{result.id}: score={result.score:.3f}")
    print(f"  Source: {result.metadata['source']}")
    print(f"  Content: {result.payload[:50]}...")
```

### 元数据过滤
```python
# 查询特定来源的文档
results = store.query(
    vector=query_vector,
    top_k=10,
    filters={"source": "report.pdf"}  # 只返回 PDF 文档
)
```

### 配置示例
```yaml
# config/settings.yaml
vector_store:
  backend: chroma
  persist_path: ./data/db/chroma
```
