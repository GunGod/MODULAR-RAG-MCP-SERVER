class OllamaLLM(BaseLLM):

        temperature: float = 0.7,

        self,

**Python 概念解释：**
- **@property 装饰器**：将方法转换为属性访问，使用 `llm.provider_name` 而不是 `llm.provider_name()`
- **类型提示 (Type Hints)**：`Optional[str]` 表示该参数可以是字符串或 None
- **异常处理**：使用 try-except 捕获 HTTP 错误、网络错误等

## 🔑 关键设计解读

### Q1: 为什么要支持两种 API 格式？

**解释：**
Ollama 早期版本使用 legacy API 格式（`/api/chat`），新版本支持 OpenAI 兼容格式（`/v1/chat/completions`）。为了确保向后兼容，代码优先尝试 OpenAI 格式，失败时自动降级到 legacy 格式。

**实现代码：**
```python
# 先尝试 OpenAI 兼容端点
response = self._client.post(self.CHAT_COMPLETION_ENDPOINT, json=payload)

# 如果返回 404，尝试 legacy 端点
if response.status_code == 404:
    legacy_payload = {
        "model": self.model,
        "messages": payload["messages"],
        "options": {
            "temperature": payload.get("temperature"),
            "num_predict": payload.get("num_tokens"),
        },
        "stream": False,
    }
    response = self._client.post(self.CHAT_COMPLETION_ENDPOINT_LEGACY, json=legacy_payload)
```

**好处：**
- ✅ 支持所有版本的 Ollama
- ✅ 用户无需升级即可使用
- ✅ 自动适配，无需配置

### Q2: 为什么需要错误信息脱敏？

**解释：**
虽然本地 Ollama 不需要认证，但错误日志可能包含其他敏感信息（如 API keys、tokens）。脱敏是一个安全最佳实践，防止日志泄露敏感数据。

**实现代码：**
```python
def _sanitize_error_message(self, error_msg: str) -> str:
    """清理错误消息，避免泄露敏感配置"""
    import re

    patterns_to_mask = [
        (r'Bearer\s+[A-Za-z0-9\._-]+', 'Bearer [REDACTED]'),
        (r'api[_-]?key["\']?\s*[:=]\s*["\']?[A-Za-z0-9\._-]+', 'api_key=[REDACTED]'),
        (r'token["\']?\s*[:=]\s*["\']?[A-Za-z0-9\._-]+', 'token=[REDACTED]'),
    ]

    sanitized = error_msg
    for pattern, replacement in patterns_to_mask:
        sanitized = re.sub(pattern, replacement, sanitized, flags=re.IGNORECASE)

    return sanitized
```

**类比：**
就像银行的 ATM 机，即使交易失败，打印的单据也不会显示完整的卡号。

**好处：**
- ✅ 符合安全合规要求
- ✅ 防止日志泄露敏感信息
- ✅ 提高系统安全性

### Q3: 连接失败为什么要提供 "ollama serve" 命令？

**解释：**
Ollama 是本地服务，最常见的错误就是服务未启动。提供启动命令可以让用户快速解决问题，而不需要去查阅文档。

**实现代码：**
```python
error_msg = (
    f"[{self.provider_name}] Unable to connect to Ollama server. "
    f"Model: '{self.model}'. "
    f"Base URL: '{self.base_url}'. "
    f"Please ensure Ollama is running and accessible. "
    f"You can start Ollama with: 'ollama serve'. "  # ← 帮助性命令
    f"Error: {str(e)}"
)
```

**好处：**
- ✅ 减少用户困惑
- ✅ 提高问题解决效率
- ✅ 改善用户体验
